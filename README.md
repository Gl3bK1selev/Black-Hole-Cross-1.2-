# Black Hole Cross

> A convenient desktop utility for monitoring computer health, interacting with system components, and fine-tuning the operating environment.

![App Screenshot](ScreenshotBlackHole.png
)

## 📖 About

Black Hole Cross is an application that combines diagnostics, resource management, and UI customization features. The project is actively evolving: functionality is continuously expanding, with new modules currently in development.

## ✨ Features

- **Real-time monitoring** — tracking CPU, RAM, storage drives, motherboard, and peripherals.
- **System interaction** — cache cleanup, audio management, network tools.
- **UI customization** — theme switching, adjustable refresh rates.
- **Cross-platform** — single codebase for Windows, Linux, and macOS.

## 🖥️ Supported Platforms

|----------|--------|
